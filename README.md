# EZ2CV
EZ2CV is a tool that analyzes gameplay videos of the rhythm game EZ2ON REBOOT : R to automatically extract patterns (charts) and save them into a single file.

It was created for the purpose of chart visualization and analysis.

## Key Features
- Takes EZ2ON gameplay videos as input and analyzes them using OpenCV.

- Converts the analyzed chart data into a lightweight and easy-to-handle single file format and returns it.
